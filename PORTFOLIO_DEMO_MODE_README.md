# Portfolio Demo Mode v57

## Nasıl açılır?
1. Normal şekilde admin hesabıyla sisteme giriş yapın.
2. Yönetim Paneli'ne gidin.
3. Üst alandaki `DEMO MOD` butonuna basın.
4. Uygulama yeniden yüklenir ve demo moda geçer.

Demo mod açıkken üstte:
`PORTFOLIO DEMO · SYNTHETIC DATA`
bandı görünür.

## Demo mod ne yapar?
- Gerçek Supabase istemcisi kullanılmaz.
- Tamamen tarayıcı içindeki sentetik demo verisi kullanılır.
- Tüm ekran izinleri açık kabul edilir.
- Ekleme / düzenleme / silme işlemleri sadece localStorage'daki demo verisini değiştirir.
- Sayfa yenilense de demo oturumu boyunca değişiklikler korunur.
- Gerçek operasyon verisine insert/update/delete yapılmaz.
- Ticket, Tahakkuk, Kargo, Hedef Kargo, Evrak, Lokasyon, Proje, Audit, Görev, Bildirim ve kullanıcı verileri sentetiktir.

## Demo moddan çıkış
Yönetim Paneli'ndeki `DEMO MODU AÇIK` butonuna veya üstteki `Demo'dan Çık` düğmesine basın.
Uygulama yeniden yüklenerek gerçek sisteme geri döner.

## Demo veri örnekleri
- 136 sentetik kargo kaydı
- 92 Hedef Kargo kaydı
- 54 evrak kaydı + seferler
- 48 tahakkuk kaydı
- sentetik lokasyon/proje/firmalar
- örnek ticket, görev, bildirim ve audit kayıtları
- demo kullanıcı aktiviteleri
- demo rapor planı ve takvim olayı

Tüm şirket, kişi, gönderi, irsaliye, VKN, telefon ve operasyon verileri portföy gösterimi için üretilmiştir.
